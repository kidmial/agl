# Contributing to Amber Guard Laboratory

Спасибо за интерес к проекту! Перед внесением изменений, пожалуйста, прочитайте это руководство.

## Процесс внесения изменений

1. Форкните репозиторий
2. Создайте ветку фичи: `git checkout -b feature/my-feature`
3. Внесите изменения с тестами
4. Запустите `go build ./... && go vet ./...`
5. Закоммитьте с понятным сообщением
6. Создайте Pull Request

## Стандарты кода

- Go 1.21+
- Все строки UI должны быть в `i18n/` (никакого хардкода)
- Ошибки обрабатываются, не игнорируются
- Комментарии на русском для внутренней логики, на английском для API
